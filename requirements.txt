# SETUP (run inside WSL2 Ubuntu terminal):
#
#   1. Confirm GPU passthrough works:
#        nvidia-smi
#      You should see "RTX 4060" and a CUDA version (12.x).
#      If this fails → install NVIDIA drivers on WINDOWS (not inside WSL).
#      WSL2 inherits the Windows GPU driver automatically.
#
#   2. Create venv:
#        python3.10 -m venv gtai_venv
#        source gtai_venv/bin/activate
#
#   3. Install everything in one shot:
#        pip install --upgrade pip
#        pip install -r requirements.txt --extra-index-url https://pypi.nvidia.com
#
#   The --extra-index-url flag is needed for the RAPIDS/NVIDIA packages.
#   Do NOT use pypi.ngc.nvidia.com — that domain is deprecated.
#
